# 여섯 번의 접근이 모두 65~70에서 멈춘 이유 — 매체의 천장 (2026-09-06)

> 사용자 채점(r6 65): "무난한데, 아직도 와우 급은 전혀 없는거같아. 뭔가 threejs로 meshy한 캐릭터나
> 요소들이 인터렉티브하게 움직이고 하는 그런 부분이 빠져서 그런가? scroll world는 보통 어떻게 해?"

## 1. 한 줄 결론

**우리는 여섯 번 디자인을 바꿨고 매체는 한 번도 바꾸지 않았다.** 정지 이미지 61장 + CSS 로는
지금까지 여섯 접근이 전부 65~70 에 수렴했다. 와우로 분류되는 산출물은 **매체가 다르다** —
스크롤로 스크럽하는 사전 렌더 영상, 또는 실시간 캔버스 렌더.

## 2. scroll-world 는 무엇인가 (원문 확인)

`github.com/oso95/scroll-world` · 9,024★ · MIT · 2026-09-05 갱신 · "A skill that turn any brand
into a scrollable 3D world landing page". **three.js 가 아니다.**

파이프라인: **N개 장면 스틸 → N개 다이브인 클립 → N−1개 커넥터 클립 → 스크럽 엔진**.
스크롤은 시간만 움직이고 카메라는 실제로 난다. 저자 표현 그대로:

> *"This is the same technique behind Apple's scroll-through product pages — the camera
> genuinely moves, scroll only drives time."*

**성패를 가르는 한 가지 규칙**은 이음매가 프레임 단위로 같아야 한다는 것이다.
커넥터의 시작 이미지 = 앞 클립의 **렌더된 마지막 프레임**, 끝 이미지 = 다음 클립의 **렌더된 첫 프레임**.
원본 스틸을 다시 쓰면 매 생성이 미묘하게 달라 이음매에서 팝이 생긴다.

비용(Seedance 2.0): 1080p 다이브 8초 ≈ $2.99 · 커넥터 5초 ≈ $1.87 → **N=6 체인 ≈ $27**,
720p ≈ $11, 480p 프리비즈는 더 싸다. 스틸은 gpt-image-2(우리가 이미 쓰는 채널).

## 5. 선택지 (비용과 함께)

| 안 | 무엇을 하나 | 비용 | 얻는 것 | 잃는 것 |
|---|---|---|---|---|
| **A. 영상 스크럽(scroll-world 방식)** | 장면 6개 스틸 → 다이브+커넥터 11클립 → 스크럽 | **1080p ≈ $27 · 720p ≈ $11**(+스틸) | Apple 식 연속 비행. 이 장르의 정본 | 단독 HTML 용량 급증(영상 인라인 대신 파일 동봉 필요). 재생성 반복 비용 |
| **B. 실시간 3D(three.js)** | 장면을 코드로 짓고 스크롤로 카메라 이동 | 생성비 0, 개발 시간 큼 | beyond·mosslight 급 · 인터랙티브 | 라이브러리 ~150KB, 모바일 성능, 우리 첫 경험 |
| **C. 캔버스 2D 연출** | 61장을 캔버스에서 합성·왜곡·파티클 | 0 | 드로 호출이 생기고 질감이 붙는다 | 3D 아님. 중간값 |
| **D. 이미지 세트 갱신** | 한 세계·한 촬영으로 새로 12~20장 | gpt-image-2 배치 ≈ $2~4 | leon 처럼 "한 세계"의 정합성 | 매체는 그대로 |
| **E. 지금 유지** | 카피·마감만 더 | 0 | 안정적 65~70 | 천장 그대로 |

권고: **A 또는 B 중 하나를 골라야 65 천장을 넘는다.** D 는 어느 쪽과도 같이 간다(정합성 문제 해결).
C 는 A·B 를 못 할 때의 차선이다.

## 6. 확인 사항

- scroll-world 는 Higgsfield/Monid CLI 를 요구한다. 우리 환경에 `higgsfield`·`monid` 가 설치·인증돼
  있는지는 **미확인**. A 를 고르면 먼저 확인해야 한다.
- three.js 는 MIT 이고 인라인 가능하지만, 우리 fx-library 예산(gzip 60KB)을 넘는다 — 예산 개정 필요.
- 이 문서는 매체 선택지를 정리한 것이지 "영상이면 90점"을 보장하지 않는다.
  실제로 leon·pocket 은 영상도 3D 도 없이 화제가 됐다.
